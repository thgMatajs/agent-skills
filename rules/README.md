# Agents rules

Reference rules for Claude Code, Codex, Cursor, and other agents.

The [skills CLI](https://skills.sh/) does **not** install this folder. Copy a rule into your agent's rules directory if you want it active.

| Rule | What it does |
| --- | --- |
| [`reuse-before-write.md`](./reuse-before-write.md) | Ambient reminder to load `reuse-before-write` before non-trivial production code. |
