# reuse-before-write

Before writing new production code for a non-trivial unit of work, load and follow the `reuse-before-write` skill. Honor `reuse` by calling the named symbol as-is. Honor `write-new` by implementing new code without editing a rejected callee in the same turn.

The [skills CLI](https://skills.sh/) does not install this file. Copy it into the agent's rules directory to make the habit ambient.
