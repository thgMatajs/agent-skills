# Authoring

Skills for writing, auditing, and improving agent skills — and for auditing the instruction files those agents read.

| Skill | What it does |
| --- | --- |
| [`auditing-skills`](./auditing-skills) | Grades a `SKILL.md` (structure → writing → contracts → security). |
| [`skill-builder`](./skill-builder) | Creates or reworks a skill; hard-gated on `auditing-skills`. |
| [`auditing-agent-rules`](./auditing-agent-rules) | Audits CLAUDE.md / AGENTS.md / vendor rules for broken commands, contradictions, stale guidance, coverage gaps, and per-session cost. |

See the [root README](../../README.md) for install commands and when to use each skill.

Add another skill here as `skills/authoring/<skill-name>/SKILL.md`.
