# Authoring

Skills for writing, auditing, and improving agent skills.

| Skill | What it does |
| --- | --- |
| [`auditing-skills`](./auditing-skills) | Grades a `SKILL.md` against the local rubric (structure → writing → contracts → security). |
| [`skill-builder`](./skill-builder) | Creates or reworks a skill and gates emission on `auditing-skills`. |
| [`auditing-agent-rules`](./auditing-agent-rules) | Audits CLAUDE.md / AGENTS.md / vendor rules for broken commands, contradictions, stale guidance, coverage gaps, and per-session cost. |

Add another skill here as `skills/authoring/<skill-name>/SKILL.md`.
